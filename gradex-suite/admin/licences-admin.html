📋 Mode d'emploi rapide
1
Le client lance GRADEX (application de bureau) → l'écran d'activation affiche son Identifiant Machine en grand, avec un bouton Copier.
2
Il vous envoie cet identifiant (ex : 4F2A-9B10-EE31-0C7D). Collez-le dans le champ Identifiant Machine ci-contre.
3
Remplissez le nom du client, choisissez la durée, puis Générer.
4
Cliquez Synchroniser vers Google Sheets → le code devient actif immédiatement.
5
Envoyez le code au client → il l'entre sur l'écran d'activation → Activer ce poste.
6
Pour bloquer : cliquez Révoquer. Le blocage prend effet au prochain contrôle de GRADEX sur ce poste (contrôle toutes les 60s si le poste est ouvert ; jusqu'à 7 jours de grâce si le poste était hors-ligne).

⚙️ Configuration Google Sheets — Instructions complètes
Prérequis : un compte Google (Gmail). Tout est gratuit. Le script Google Apps Script sert de serveur de vérification pour GRADEX (routes appelées par src/services/licenseClient.js, exactement comme pour BV-Calc — ce mécanisme n'a pas changé).
Étape 1 — Créer le Google Sheet
  1. Ouvrez sheets.google.com → Nouveau classeur
  2. Nommez-le GRADEX_Licences
  3. En ligne 1, créez ces colonnes exactement : A: code    B: machineId    C: client    D: days    E: status    F: createdAt    G: note

Étape 4 — Configurer chaque copie de GRADEX distribuée
  1. Dans le projet GRADEX, ouvrez le fichier license-config.json (à la racine) et vérifiez que licenseServerUrl contient bien la même URL que ci-dessus
  2. Ce fichier fait partie des sources livrées à chaque client (embarqué dans l'archive .asar Electron) — la même URL est utilisée pour tous les postes, seul l'Identifiant Machine change
✓ Une fois configuré : chaque démarrage de GRADEX (et chaque contrôle périodique, toutes les 60s) contacte votre Google Sheet. Si vous modifiez le code du script après un premier déploiement, utilisez Déployer → Gérer les déploiements → ✏️ → Nouvelle version pour que les changements prennent effet (l'URL reste la même). En cas de coupure réseau, le poste client garde l'accès jusqu'à 7 jours depuis sa dernière vérification réussie (tolérance hors-ligne), puis se bloque automatiquement si le serveur reste injoignable.
